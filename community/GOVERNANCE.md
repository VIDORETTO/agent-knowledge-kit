# Governance and maintainers

`consulta-documentacao` is maintained by the repository owners listed in
`.github/CODEOWNERS`. Maintainers are responsible for reviewing changes,
protecting user data, deciding release compatibility, and recording security
and support decisions.

Small bug fixes may be merged after review and passing gates. Changes to public
contracts, security controls, release policy, dependency allowlists or support
claims require explicit maintainer review. Community contributors retain
copyright in their contributions under the repository license.

Branch protection, required reviewers and release permissions are operational
settings that must be confirmed by a human administrator before publication of
each release candidate.
