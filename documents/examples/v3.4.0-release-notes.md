# acme-api-client — Release notes v3.4.0

## Novidades

- `Client.request()` agora aceita `compress: bool` (padrão `False`) para
  habilitar gzip nas respostas via header `Accept-Encoding: gzip`.
- Middleware de logging: `Client.log_requests = True` adiciona 1 linha JSON
  por request em stderr (anonymizado — sem content headers).

## Mudanças

- O header `x-acme-key` agora é obrigatório também em `GET /v3/health`
  (antes aberto). Health checks com agente antigo quebravam à meia-noite.
- `page_size` continua máx. 500 — sem alteração.

## Deprecações

- `Client.join(endpoint, key)` — removidos da v4 (já deprecado na v3.2.0).
- `Client.request(..., body: str)` — agora só `dict`.

## Compatibilidade

- Python 3.11+ e Node 18+ mantidos; sem mudanças de assinatura no
  `request()` além do novo kwarg `compress` (posicional não mudou).
